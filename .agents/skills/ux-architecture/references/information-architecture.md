# Information architecture

El mapa es la superficie primaria. La navegación de capítulos debe ser secundaria y compacta; el detalle de una misión debe aparecer bajo demanda, sin tapar permanentemente el mapa.

Orden de comprensión:

1. Curso y capítulo actuales.
2. Posición y progreso en el mapa.
3. Misiones disponibles y bloqueadas.
4. Razón del bloqueo y requisitos.
5. Evidencia, acción y próximo desbloqueo.

Usar progressive disclosure para mostrar metadatos, entregables y contexto ampliado solo cuando ayuden a actuar. Mantener visibles las relaciones que explican la progresión.
