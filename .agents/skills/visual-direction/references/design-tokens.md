# Design tokens

`DESIGN.md` es la fuente de verdad mientras el sistema está en construcción. Aún no se fijan paleta ni tipografías definitivas.

Familias a definir cuando haya evidencia de producto:

- color de fondo, superficie, texto, borde y estados;
- escala tipográfica y pesos;
- spacing, radios y grosor de borde;
- tamaños de nodo, conectores y hitos;
- duración y easing para cambios significativos.

Los tokens deben permitir variantes por creador en color, typography, iconography y elementos decorativos seleccionados. Evitar tokens que solo sirvan para un curso concreto.
