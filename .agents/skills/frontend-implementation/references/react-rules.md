# React rules

- Mantener componentes pequeños, enfocados y componibles.
- Separar tipos y datos de dominio de la presentación.
- Hacer explícitos los estados y eventos; evitar estados implícitos derivados de estilos.
- Diseñar APIs internas que no expongan detalles innecesarios de la librería de grafo.
- Evitar valores hardcodeados de un curso, creador o viewport.
- Considerar renderizado, memoización y carga de datos solo cuando la evidencia lo requiera.
