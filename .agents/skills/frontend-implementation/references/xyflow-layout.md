# xyflow layout

El layout debe favorecer lectura de progresión, espacios entre ramas y visibilidad de convergencias. No usar posiciones aleatorias ni un layout que oculte dependencias.

Definir una estrategia determinista, un viewport inicial útil y comportamiento razonable al cambiar de capítulo o revelar una rama. Mantener el mapa protagonista en desktop y adaptable en espacios embebidos.
