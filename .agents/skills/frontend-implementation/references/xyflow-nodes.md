# xyflow nodes

Los custom nodes deben representar una misión o hito con estructura semántica, etiqueta, estado, progreso y acción clara. La apariencia no debe ser el único lugar donde viva el estado.

Separar el modelo de dominio de la configuración específica de la librería. Definir handles y conexiones de forma consistente con la dirección de progresión; contemplar nodos de ramas y convergencias.
