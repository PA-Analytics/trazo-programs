# Accessibility checklist

- [ ] Teclado: recorrido, selección, apertura, cierre y retorno de foco.
- [ ] Foco visible y orden lógico.
- [ ] Labels y descripciones para nodos, edges, controles y paneles.
- [ ] Contraste suficiente en texto, controles y estados.
- [ ] Estados comprensibles sin color único.
- [ ] Alternativa al canvas visual.
- [ ] Locked explica requisito y acción posible.
- [ ] Available, active y completed tienen señales redundantes.
- [ ] Zoom/pan accesibles.
- [ ] Reduced motion respetado.
