# Graph accessibility

Cada nodo debe exponerse como una unidad navegable con nombre, tipo, estado, requisitos y siguiente consecuencia. La selección debe abrir un detalle accesible y anunciar cambios relevantes.

Proporcionar una vista lineal o lista equivalente que ordene capítulos, misiones, dependencias, bloqueos y milestones. El usuario debe poder llegar a cualquier misión sin arrastrar el canvas.

Zoom y pan necesitan controles de teclado, botones con nombres y un estado visible. No exigir precisión de puntero para seleccionar un nodo.
