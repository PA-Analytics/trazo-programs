# Critique framework

Evaluar en este orden:

1. comprensión inmediata;
2. jerarquía;
3. progresión;
4. interaction clarity;
5. visual consistency;
6. density;
7. accessibility;
8. distinctiveness;
9. AI-slop detection.

Preguntar si el usuario entiende dónde está, qué puede hacer, qué está bloqueado, por qué y qué desbloquea después. Comparar la interfaz con la hipótesis y `DESIGN.md`, no con preferencias personales.
