# Severity rubric

- **P0**: bloquea el uso, una tarea crítica o la comprensión de la progresión. Corregir antes de continuar.
- **P1**: causa daño UX importante o confusión frecuente, aunque exista un workaround.
- **P2**: problema visible o moderado que degrada claridad, consistencia o accesibilidad.
- **P3**: polish, detalle menor o mejora no bloqueante.

Formato obligatorio por hallazgo:

`Problema → evidencia → impacto → cambio recomendado`

Asignar la severidad por impacto observable, no por esfuerzo de implementación.
