# TRAZO — Product translation

## Marketing surface vs product surface

| Marketing surface | Product surface |
|---|---|
| Editorial, expresiva, abierta | Compacta, funcional y state-driven |
| Headlines grandes | Títulos de capítulo y misión en display |
| Storytelling secuencial | Jerarquía operativa y siguiente acción |
| Mapa como demostración | Mapa como modelo de dependencias |
| Aire amplio | Densidad informativa controlada |

Portar la marca significa portar la lógica de lectura, no repetir la composición de la landing.

## Traducción por elemento

| Elemento | Regla de producto |
|---|---|
| Navigation | Geist UI, compacta, una acción primaria; indicar ubicación y progreso sin teñir todo de azul. |
| Quest map | Nodos y edges representan dependencias reales; el mapa no es un dashboard ornamental. |
| Nodes | Done: índigo + check. Active: tinta + centro índigo y mayor escala. Available: papel + borde tinta. Locked: piedra + borde discontinuo + explicación. Milestone: diamante. |
| Routes/edges | Completada: índigo continua. Disponible: tinta discontinua. Futura/bloqueada: piedra discontinua. El grosor y patrón también comunican estado. |
| Mission panel | Título, acción concreta, evidencia, feedback y unlock; el panel responde “qué hago ahora”. |
| Buttons | Índigo solo para la acción prioritaria; hover tinta; secundario en papel/tinta; Geist. |
| Selected | Contención tinta, borde fuerte y señal índigo; no depender de un fondo azul total. |
| Active | Trabajo actual, alta legibilidad, indicador de estado y acción inmediata. |
| Completed | Evidencia satisfecha, check y ruta índigo; no confundir con “visto”. |
| Locked | Dependencia visible, acción explicativa o requisito; piedra no puede ser el único indicador. |
| Optional | Ruta secundaria y neutral, con etiqueta explícita; no competir con el camino principal. |
| Milestone | Hito de capítulo o resultado; diamante o forma diferenciada, reservado para cambios relevantes. |
| Evidence | Prueba concreta y legible: enlace, archivo, entrega o feedback; nunca porcentaje vacío. |
| Unlock | Acción habilitada por evidencia; fila o relación visual índigo/tinta. |
| Progress | Ruta, nodos y conteo con significado; evitar KPI genérico si no representa avance real. |
| Empty states | Papel + tinta, explicación de la siguiente acción y ruta de entrada; no ilustración genérica ni CTA azul gigante. |

## El azul TRAZO

El índigo representa principalmente progreso, ruta, acción, selección y desbloqueo. No significa “pintar toda la aplicación de azul”. Un fondo azul amplio solo se justifica como zona de decisión o afirmación; en producto, usarlo con mucha más parsimonia que en una pieza editorial.

## Tipografía en producto

Condensed display: chapter titles, milestone labels y large section identity. Sans UI/body: navegación, botones, metadata, labels, formularios, misión densa, evidencia, feedback y todos los controles. Nunca usar display en cada botón o dato.

## Same brand, different density

La landing comunica la ruta desde lejos; el producto ayuda a recorrerla de cerca. Conservar papel, tinta, índigo semántico, bordes y geometría del mapa. Reducir tamaño display, aire, texturas, marcos protagonistas y movimiento. Aumentar claridad de estados, affordances, feedback, foco y densidad útil.

## Secuencia recomendada de portabilidad

1. Mapear los estados reales del producto a los estados TRAZO.
2. Instalar primero tokens y tipografía, sin reemplazar componentes a ciegas.
3. Aplicar reglas a navegación, mapa y mission panel.
4. Auditar contraste, focus, touch targets y reduced motion.
5. Revisar que el índigo siga señalando decisiones y no decoración.
