# TRAZO — LANDING PAGE BRAND & VISUAL DIRECTION GUIDE

## STATUS

This document defines the current brand and visual direction for the TRAZO landing page.

Use it as a persistent design guide when modifying the landing page, marketing surfaces, brand graphics, typography, color, motion, diagrams, route/node visuals, and product previews shown in marketing.

This is a directional system, not permission to redesign everything in every task.

For every implementation task:

1. Respect this brand direction.
2. Preserve compatibility with it.
3. Implement only the explicit requested scope.
4. Do not refactor unrelated working components simply to make them conform more closely to this document.
5. Prefer gradual migration over visual rewrite.
6. If an explicit task conflicts with this guide, report the conflict before implementing.

---

# 1. BRAND FOUNDATION

TRAZO is:

> The platform where methodologies are executed.

TRAZO is not primarily an LMS, chatbot, AI tutor, task manager, course generator, or gamified checklist.

The central product primitive is:

## VERIFIED ACTION

Not:

watched content -> checked box -> progress

But:

ACTION -> EVIDENCE -> VERIFICATION -> VALID PROGRESS

The landing page should visually communicate this difference.

---

# 2. CORE PSYCHOLOGICAL JOB

TRAZO helps reduce uncertainty about one's own action and progress.

The desired learner feeling is:

> I know where I am, I understand what comes next, and I know that my progress here is real.

The brand should reinforce orientation, autonomy, competence, perceived control, real progress, mastery, clarity, and confidence in the validity of progress.

TRAZO should not manufacture fake momentum. Progress should always feel consequential.

---

# 3. BRAND ARCHETYPE

Primary archetype:

## SAGE x EXPLORER

Sage contributes understanding, clarity, precision, intelligence, structure, and judgment.

Explorer contributes movement, autonomy, routes, discovery, progression, possibility, and what comes next.

There is also a third archetypal influence:

## RULER — BUT ONLY AS SYSTEM BEHAVIOR

The Ruler should live in deterministic rules, verification, prerequisites, policies, workflow integrity, and valid transitions.

It should not dominate the expressed personality of the brand. TRAZO must not feel authoritarian, bureaucratic, rigid, or enterprise-dead.

---

# 4. BRAND CHARACTER

A useful mental model:

## A TECHNICAL EXPEDITION GUIDE WITH A CARTOGRAPHER'S MIND

TRAZO understands the territory, makes complexity legible, knows where the learner currently is, shows valid paths forward, does not fabricate shortcuts, does not change rules arbitrarily, and moves with the learner rather than observing from above.

The Cartographer is primarily TRAZO's visual world, not its complete psychological identity. A traditional cartographer merely maps; TRAZO makes verified action consequential.

Brand psychology: Sage x Explorer  
System behavior: Ruler  
Visual world: Cartography / routes / nodes / states  
Core primitive: Verified Action

---

# 5. CENTRAL BRAND TENSION

## PRECISION x PROGRESS

Alternative wording:

## STRUCTURE x MOVEMENT

TRAZO should always contain both.

Too much precision without movement becomes corporate, static, sterile, and like technical documentation.

Too much movement without precision becomes gamified, superficial, childish, and like a motivational app.

The brand succeeds when it feels:

> Structurally serious but behaviorally alive.

---

# 6. DESIRED PERSONALITY

TRAZO should feel precise, intelligent, alive, oriented, deliberate, contemporary, confident, curious, calm, and consequential.

It can have personality without becoming loud.

---

# 7. ANTI-PERSONALITY

Avoid making TRAZO feel magical, childish, corporate, bureaucratic, generic, motivational, hyperactive, decorative, over-designed, like an AI startup, crypto-like, or gamer-like.

---

# 8. GEN Z / CULTURAL RELEVANCE

Do not attempt to make TRAZO look Gen Z directly.

Avoid forced slang, random memes, excessive emoji, intentional misspellings, childish mascot behavior, trend-chasing visual systems, chaotic colors used merely to appear young, and exaggerated internet personality.

The objective is:

> A brand younger users genuinely find interesting, not a brand visibly designed to target young people.

Coolness should come from a strong point of view, originality, aesthetic quality, product truth, consistency, confident restraint, visual tension, recognizable design decisions, and moments of controlled energy.

---

# 9. VISUAL WORLD

The visual vocabulary should emerge naturally from the product:

- TRAZO / trace
- route
- path
- node
- waypoint
- destination
- branch
- state
- checkpoint
- progress
- evidence
- connection
- unlock
- blocked path
- completed path

These must become a real visual system, not isolated explanatory diagrams. Eventually, a user should be able to see a TRAZO route graphic without the logo and recognize the brand.

---

# 10. ROUTES AND NODES AS PROPRIETARY BRAND ASSETS

Develop consistent semantics:

## BLOCKED

Muted or inactive. A future path exists but cannot currently be traversed.

## AVAILABLE

Visually active. The learner can act here now.

## CURRENT

Stronger focus than available. Represents the relevant current position or action.

## COMPLETED / VERIFIED

Represents real validated progress, not simply a checked item.

## FUTURE

Visible enough to create orientation and anticipation without competing with the current action.

## BRANCH

Shows legitimate choice within methodology constraints. Do not use branches merely as decoration.

Exact visual treatments may evolve; the semantic distinctions must remain.

---

# 11. MOTION IS PART OF THE BRAND

TRAZO talks about advancing, traversing, unlocking, progressing, and changing state.

## MOTION MUST COMMUNICATE MEANING

Good examples:

- A line draws because a path is being traversed.
- A node activates because it becomes available.
- A completed segment becomes visually established.
- A branch reveals because a new option exists.
- A checkpoint changes state after verification.
- A path continues after valid progress.

Bad examples:

- Random floating objects.
- Ambient particles.
- Blobs moving behind text.
- Unnecessary parallax everywhere.
- Constant pulsing.
- Decorative glows.
- Gratuitous scroll animation.

Motion should teach the user how TRAZO behaves.

---

# 12. MOTION RHYTHM

## CALM BY DEFAULT. ENERGETIC WHEN SOMETHING CHANGES.

Most surfaces should feel controlled and readable.

Energy should appear during unlock, verification, transition, progress, route revelation, and important interaction.

Do not maintain maximum energy constantly. The contrast between calm and movement makes meaningful moments stronger.

---

# 13. CURRENT LANDING PROBLEM

The current landing has a strong foundation: clear typography, good editorial feeling, restrained color, negative space, conceptual diagrams, and confident copy.

However, it currently feels too flat, static, repetitive, uniform, editorial, and passive.

The product speaks about maps, paths, progression, action, and unlocking while much of the visual experience behaves like a static editorial poster.

The goal is not to make TRAZO more colorful. The goal is:

> Make TRAZO feel alive without losing precision.

---

# 14. PAGE RHYTHM

Avoid repeating:

background -> headline -> paragraph -> simple graphic -> same background

Create visual chapters. A possible rhythm is:

LIGHT / QUIET  
-> ACTIVE VISUAL SYSTEM  
-> DARK / HIGH CONTRAST  
-> LIGHT SURFACE  
-> PRODUCT / ROUTE EXPERIENCE  
-> DARK OR HIGH-IMPACT CLOSING SECTION

Do not alternate backgrounds mechanically. Section changes should correspond to conceptual transitions in the story.

---

# 15. COLOR DIRECTION

The beige or cream direction is not sacred.

Current working direction:

## MINERAL / STONE + INK + COBALT

Move from paper / ink / highlighter toward mineral / structure / signal.

---

# 16. CURRENT WORKING COLOR HYPOTHESIS

These are exploratory values, not permanently locked brand tokens.

### Main light background

#F1F1EC

A soft mineral or stone neutral, closer to off-white or subtle gray than yellow beige. It should provide a comfortable, calm, neutral foundation, reduce glare, work with dark ink, and avoid generic pure-white SaaS surfaces.

### Main ink

#141A16

A very dark green-black for primary typography, structure, dark sections, authority, and brand grounding. Prefer this type of near-black over pure black where appropriate.

### Primary route / actionable signal

#3657FF

This is not merely TRAZO's blue. Its meaning is:

## YOU CAN MOVE HERE.

Use it for the next available path, primary action, active route, important interactive emphasis, relevant CTA, and current possibility. Do not spread it everywhere for decoration; unnecessary blue weakens its meaning.

### Light surface

#E7E8E2

Use for cards, elevated light regions, and subtle separation from the main background. Prefer surface contrast, borders, and composition over excessive shadows.

### Dark surface

#111612 or #141A16

### Text on dark

#ECEDE7

Avoid absolute white where unnecessary.

---

# 17. IMPORTANT COLOR PRINCIPLE

Do not collapse:

- Brand color
- Route / navigation color
- Semantic product colors

They are different systems.

TRAZO will eventually need semantic states such as PASS, AVAILABLE, BLOCKED, CLARIFY, REWORK, and HUMAN REVIEW.

A preliminary direction may include:

- AVAILABLE / NEXT -> cobalt blue
- PASS -> green
- CLARIFY -> amber
- REWORK -> controlled red or coral
- HUMAN REVIEW -> distinct review color
- BLOCKED -> muted neutral

Final semantic colors must be validated separately for accessibility, contrast, dark mode, color-blind differentiation, and consistency.

---

# 18. DARK SURFACES / NIGHT COMFORT

Do not solve nighttime comfort simply by choosing a slightly darker beige. TRAZO should be compatible with a true dark visual system.

Possible direction:

- Background: #111612
- Surface: #192019
- Elevated surface: #202820
- Primary text: #ECEDE7
- Muted text: approximately #A5AAA3
- Available route: a lighter cobalt variant

Dark mode must preserve semantic meaning. It must remain mineral / ink / signal, not neon cyberpunk, a glowing AI dashboard, or a gaming interface.

---

# 19. TYPOGRAPHY

The current condensed or heavy display typography is a valuable personality asset and should not necessarily be removed.

Use display typography primarily for hero statements, important positioning, section titles, large numbers, and strong moments.

Use a highly legible sans-serif for explanatory copy, controls, product UI, evidence, states, labels, longer reading, and dense information.

## DISPLAY = CHARACTER  
## UI / BODY = CLARITY

Increase typographic contrast between hierarchy levels so the user instantly understands where they are, what matters, what is explanation, and what is actionable.

---

# 20. HERO DIRECTION

The hero should remain confident and relatively restrained, but demonstrate TRAZO rather than merely describe it.

A strong conceptual direction is a flat methodology or content structure visibly transforming into an executable path:

CONTENT  
-> ACTION  
-> EVIDENCE  
-> VERIFIED  
-> NEXT PATH

Or:

START  
-> NODE  
-> VERIFIED NODE  
-> BRANCH  
-> NEXT ACTION

The exact concept may vary. The hero must immediately introduce movement, state, and progression. Avoid purely decorative illustrations.

---

# 21. SHOW, DON'T ONLY EXPLAIN

Where possible, explain TRAZO concepts by letting the page behave like TRAZO.

Instead of saying “TRAZO unlocks the next mission,” show:

locked node -> verification -> route draws -> node becomes available

Instead of saying “Students know what comes next,” show:

current position -> available path clearly highlighted

The landing should increasingly become a small experiential proof of the product's philosophy.

---

# 22. WHAT TO KEEP FROM CURRENT TRAZO

Preserve unless there is a clear reason to change:

- Confident editorial tone.
- Restrained design.
- Dark ink foundation.
- Condensed display type as a recognizable asset.
- Strong use of negative space.
- Conceptual route and node language.
- Avoidance of generic AI aesthetics.
- Precise copy.
- Absence of unnecessary superlatives.
- Serious treatment of the creator's methodology.

The current identity is not broken. The goal is evolution.

---

# 23. WHAT SHOULD EVOLVE

Priorities:

1. Greater visual rhythm between sections.
2. More depth through surfaces and contrast.
3. Routes and nodes becoming a real brand system.
4. Meaningful motion.
5. Stronger visual representation of state.
6. Better separation between display typography and functional typography.
7. More deliberate color semantics.
8. More moments of dynamic progression.
9. Stronger product demonstration inside marketing.
10. Less visual repetition.

---

# 24. WHAT NOT TO ADD

Avoid default modern AI or startup clichés:

- Purple-blue gradient branding.
- Auroras.
- Glowing spheres.
- Sparkles.
- Random AI stars.
- Excessive glassmorphism.
- Decorative 3D blobs.
- Fake terminal interfaces.
- Cyberpunk visual language.
- Excessive neon.
- Arbitrary grids.
- Generic gradient cards.

TRAZO uses AI, but does not need to look like AI. Intelligence should be visible through product behavior.

---

# 25. NO FAKE AGENCY IN MARKETING

If marketing shows “Evaluating…”, there should be a real evaluation in the product or demo being represented.

If TRAZO says “I remembered…”, there should be actual persisted context.

If a node appears unlocked, there should be a legitimate state transition underlying that representation.

The marketing experience must respect the same principle as the product:

> THE MAP REFLECTS REALITY.

Do not visually fake capabilities that do not exist.

---

# 26. BRAND RECOGNITION TEST

When evaluating a proposed component, ask:

## If we hide the TRAZO logo, could this still eventually become recognizable as TRAZO?

A mature TRAZO identity should be recognizable through combinations of route geometry, node semantics, typography, surfaces, motion, cobalt actionable signal, dark ink, and state transitions rather than logo repetition.

---

# 27. DESIGN TEST

Before accepting a significant visual change, evaluate:

1. Does this create greater orientation?
2. Does it communicate progression?
3. Does movement represent meaning?
4. Does it feel precise?
5. Does it feel alive?
6. Does it remain trustworthy to a creator or founder?
7. Would a learner want to see what happens next?
8. Is it becoming more recognizable as TRAZO?
9. Does it solve a product or brand communication problem rather than merely decorate?
10. Does it avoid generic AI aesthetics?
11. Does the page remain calm enough to understand?
12. Is energy concentrated around meaningful events?
13. Are routes and nodes becoming more proprietary?
14. Is the visual hierarchy clearer than before?
15. Are color meanings becoming more consistent?

---

# 28. BRAND SUMMARY

## TRAZO IS A SERIOUS SYSTEM THAT FEELS ALIVE.

Product truth: Verified Action.

Psychological promise:

> I know where I am, I understand what comes next, and my progress is real.

Archetypes: Sage x Explorer.  
Structural behavior: Ruler.  
Visual world: Cartography of execution.  
Core tension: Precision x Progress.  
Default emotional state: Calm, clear, controlled.  
Peak emotional state: Momentum, unlock, verified advancement.

Visual philosophy: Structure stays quiet. Progress becomes visible.

Motion philosophy: Movement means something.

Color philosophy: Neutral structure + strong actionable signal + explicit semantic states.

AI philosophy: AI is infrastructure, not visual identity.

---

# 29. IMPLEMENTATION PRIORITY FOR LANDING REFACTOR

Prefer this sequence:

### Phase 1 — Foundations

- Color tokens.
- Surfaces.
- Typography hierarchy.
- Spacing and rhythm.
- Dark and light section strategy.

### Phase 2 — TRAZO Visual Language

- Route geometry.
- Node styles.
- Path states.
- Branch styles.
- Graphical rules.

### Phase 3 — Motion System

- Route draw.
- Node activation.
- Unlock.
- Progress transition.
- Scroll-triggered storytelling where meaningful.

### Phase 4 — Hero

Use the established visual and motion language to rebuild the hero. Do not invent a completely separate hero aesthetic.

### Phase 5 — Section-by-section refinement

Migrate existing sections toward the system without unnecessary rewrite.

---

# 30. FINAL RULE

When uncertain between adding something visually exciting and making real progress more legible, choose:

## MAKE PROGRESS MORE LEGIBLE.

Then make that legibility beautiful.

That is TRAZO.
